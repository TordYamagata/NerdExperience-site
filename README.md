# 🎮 Nerd Experience

Uma interface moderna de e-commerce inspirada no universo geek, criada com **HTML, CSS e JavaScript**.

O projeto foi reformulado com foco em uma aparência mais limpa, responsiva e moderna, reduzindo o excesso de imagens e melhorando a organização visual da página.

---

## 🚀 Sobre o projeto

O **Nerd Experience** é um site fictício voltado para produtos do universo geek, como:

- 🎵 CDs e músicas
- 📚 HQs
- 🦸 Figures
- 👾 Funkos
- 🎮 Produtos colecionáveis
- 🧙 Itens relacionados à cultura geek

A proposta da reformulação foi criar uma experiência visual mais agradável utilizando menos imagens e aproveitando recursos de CSS como:

- Gradientes
- Sombras
- Efeitos neon
- Cards
- Animações
- Layout responsivo

---

## ✨ Funcionalidades

O projeto possui:

- ✅ Menu de navegação
- ✅ Layout responsivo
- ✅ Menu mobile

---

## 🛒 Carrinho

Os botões **Adicionar ao carrinho** possuem uma implementação simples em JavaScript.

Ao clicar em um produto:

1. O contador do carrinho aumenta.
2. O botão informa que o produto foi adicionado.
3. Uma notificação aparece na tela.
4. Após alguns segundos, o botão retorna ao estado original.

> O carrinho é apenas demonstrativo e não utiliza banco de dados.

---

## 🔍 Pesquisa

O botão de pesquisa abre um modal com um campo para busca.

O modal pode ser fechado:

- pelo botão **X**
- clicando fora da caixa de pesquisa
- pressionando a tecla **ESC**

---

## 📧 Newsletter

O projeto também possui um formulário simples de newsletter.

Após inserir um e-mail e clicar em **Inscrever-se**, uma mensagem de confirmação aparece na tela.

O formulário é apenas demonstrativo e não envia dados para um servidor.

## ▶️ Como executar o projeto

Não é necessário instalar nenhuma dependência.

### 1. Clone o repositório

```bash
git clone https://github.com/TordYamagata/Nerd-Experience-Site.git
```

### 2. Entre na pasta

```bash
cd Nerd-Experience-Site
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

diretamente no navegador.

Você também pode utilizar a extensão **Live Server** no Visual Studio Code.

---

## 💻 Visual Studio Code

Se estiver utilizando o VS Code:

1. Abra a pasta do projeto.
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html`.
4. Selecione:

```text
Open with Live Server
```

O projeto será aberto automaticamente no navegador.
